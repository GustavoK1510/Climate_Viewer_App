# 🌦️ Climate Viewer

**Climate Viewer** is a minimalist Flutter project that displays real-time weather information based on the user's current location or any city searched by the user.

The application uses the **OpenWeather API** together with geolocation and reverse geocoding services to retrieve weather data and present it through a clean, intuitive, and animated interface.

## ✨ Features

- 📍 Automatic location detection
- 🌍 Reverse geocoding to identify the current city
- 🔍 Search for weather in any city
- 🏠 Dedicated Home Page displaying the user's local weather
- 🌤️ Individual Weather Page for searched locations
- 🌡️ Real-time temperature display
- ☁️ Current weather condition
- 🎬 Dynamic Lottie animations based on weather conditions
- 🎨 Minimalist and easy-to-use interface

## 🛠️ Technologies

- Flutter
- Dart
- OpenWeather API
- Geolocator
- Geocoding
- Lottie
- HTTP
- flutter_dotenv

## 📌 Purpose

This project was created as a learning exercise to practice Flutter development, REST API integration, geolocation, reverse geocoding, navigation between pages, state management, and asynchronous programming while maintaining a clean and minimalist design.
